
# تطبيق الباحث القرآني — محرك بحث متقدم في القرآن الكريم

تطبيق متكامل للبحث في القرآن الكريم مبني باستخدام React Native / Expo.

## ✨ المميزات
- بحث ذكي في كامل المصحف أو في جزء محدد.
- دعم البحث بالكلمات الملتصقة (مثل: غفوررحيم) وتفكيكها تلقائياً.
- تظليل دقيق للكلمات مع الحفاظ على التشكيل.
- تشغيل التلاوة الصوتية للآية من مواقع موثوقة.
- إحصائيات وتلخيص لتكرار الكلمات في السور.
- واجهة مستخدم عربية أنيقة وسريعة.

## ⚠️ تنويه هام جداً
هذا المشروع مفتوح المصدر ومقدم **"كما هو" (AS IS)** مجاناً لوجه الله تعالى.
- **لا يوجد دعم فني** لهذا الكود.
- **لا يمكن التواصل** مع المطور لأي استفسار.
- **لا يتم قبول** أي طلبات سحب (Pull Requests) أو مساهمات أو بلاغات أخطاء.
- لك الحرية الكاملة في نسخ الكود، تعديله، استخدامه، أو تطويره كما تشاء دون أي قيود.

## 🚀 كيفية التشغيل للمطورين
1. تأكد من تثبيت [Node.js](https://nodejs.org/) و [Expo CLI](https://docs.expo.dev/get-started/installation/).
2. قم بتنزيل أو استنساخ (Clone) هذا المستودع.
3. افتح موجه الأوامر (Terminal) في مجلد المشروع ونفذ:
   ```bash
   npm install
   ```
4. لتشغيل التطبيق:
   ```bash
   npx expo start
   ```
